# Java Tic-Tac-Toe

A two-player desktop Tic-Tac-Toe game built with Java Swing.

## Requirements

- Java Development Kit (JDK)

## Run

```bash
javac TicTacToe.java
java TicTacToe
```

## Features

- Clickable 3×3 board
- Two-player X and O turns
- Win and draw detection
- Score tracking and new-game control
